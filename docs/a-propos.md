# À propos de PASSIONCARBU ❤️

PASSIONCARBU est une base documentaire indépendante consacrée à l'identification, au fonctionnement, aux calibrages et au réglage des carburateurs automobiles, avec un intérêt particulier pour les montages Peugeot, Citroën et Renault.

## État du site

Le site est en cours de construction. Certaines fiches sont déjà détaillées, tandis que d'autres sont encore en préparation. Les informations sont complétées et corrigées progressivement.

## Sources et méthode

Les fiches sont constituées à partir de documentation technique, de revues et manuels d'atelier, de catalogues de pièces, de références constructeur et de relevés réalisés sur des carburateurs identifiés. Lorsque cela est possible, les sources précises sont ajoutées directement aux fiches.

## Avertissement technique

Les affectations et calibrages peuvent différer selon le millésime, le pays de commercialisation, le moteur ou une évolution de production. Un carburateur extérieurement identique peut recevoir des réglages internes différents.

Avant de commander des pièces ou de modifier un réglage, vérifiez toujours :

- le type exact du carburateur ;
- le repère constructeur ;
- la référence Solex, Weber ou autre ;
- le code moteur ;
- les valeurs présentes sur le carburateur monté sur le véhicule.

PASSIONCARBU est un site documentaire indépendant et n'est pas affilié aux constructeurs ou équipementiers mentionnés.
